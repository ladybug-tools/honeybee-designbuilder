honeybee_designbuilder.site module¶

A module for functions related to DesignBuilder site and climate.

honeybee_designbuilder.site.find_closest_location(target_lat, target_lon, library_path=None)[source]¶

Get the data of the closest location in the DesignBuilder climate library.

Parameters:

  • target_lat – The latitude of the project site location, for which the data of the closest climate file in the climate library will be returned.

  • target_lon – The longitude of the project site location, for which the data of the closest climate file in the climate library will be returned.

  • library_path – Optional path the the DesignBuilder climate library file. If None, the LocationTemplates.dat file within this package will be used. (Default: None).

Returns:

A dictionary with keys representing different DesignBuilder location properties and values representing the closest location to the target_lat and target_lon in the DesignBuilder climate library. Will be None if no closest location could be determined.

honeybee_designbuilder.site.modify_template_for_site(xml_template, project_info)[source]¶

Modify an ElementTree of a DesignBuilder template given a ProjectInfo object.

This involves setting the BuildingOrientation in the template using the north defined in the project_info. If the project_info contains a location, this will also be used to set all of the location attributes and also set the weather data to the closest location found in the DesignBuilder climate library. This means that the weather_urls contained in the project_info are always ignored given that DesignBuilder does not accept external weather files and sets everything up using its own internal climate library.

Parameters:

  • xml_template – The root of an ElementTree parsed from a DesignBuilder template.

  • project_info – A Ladybug ProjectInfo object to set the site attributes of the project.
